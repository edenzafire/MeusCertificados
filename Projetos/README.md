# 🛡️ Computer Security Lab (Stepik)

Este repositório contém os meus **Laboratórios, Anotações Técnicas e Writeups** desenvolvidos durante o curso **"Компьютерная безопасность": курс для начинающих** *(Segurança de Computadores: Curso para Iniciantes)* oferecido pela plataforma **Stepik**.

O objetivo deste projeto é documentar de forma prática o aprendizado em fundamentos de cibersegurança, análise de protocolos de rede, administração e segurança de sistemas operacionais, além da resolução de desafios no formato **CTF (Capture The Flag)**.

---

## 📌 Visão Geral do Curso

* **Plataforma:** Stepik
* **Curso:** Компьютерная безопасность: курс для начинающих
* **Foco Principal:** Fundamentos de Cibersegurança, Arquitetura de Redes, Segurança de SO e Práticas de CTF.
* **Status:** 🛠️ Em Desenvolvimento / Estudo Ativo
